Dies ist ein offizieller statischer ffmpeg-/ffprobe-Build für Windows
(essentials build, GPLv3, von gyan.dev, https://www.gyan.dev/ffmpeg/builds/),
hier eingebettet, damit VOXini Video Studio als fertig gebaute .exe niemals
von einer separaten, vom Nutzer selbst installierten FFmpeg-Installation
abhängt. Die vollständige GPLv3-Lizenz liegt in LICENSE-FFmpeg.txt bei.
